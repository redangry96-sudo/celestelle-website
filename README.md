
# Celestelle Jewellery Website

A responsive jewellery storefront created using HTML, CSS and Vanilla JavaScript.

## Features

- Responsive homepage
- Jewellery category sections
- Featured products
- Product detail pages
- Collection filtering
- Product sorting
- Product search
- Wishlist
- Shopping cart
- Quantity management
- Cart subtotal calculation
- About Us page
- Contact page
- Newsletter interface
- Mobile navigation
- LocalStorage for cart and wishlist

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts
- Unsplash product photography

## Installation

No npm installation is required.

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open index.html using Live Server.
4. Explore the website.

## Project Structure

celestelle/
- index.html
- styles.css
- script.js
- assets/
  - celestelle-logo.png
- README.md

## Customization

Product information is stored in script.js.

Update:
- Product names
- Prices
- Categories
- Product descriptions
- Product images

Add the real business email in CONTACT_EMAIL.

## Important

This is a frontend-only ecommerce demonstration.

Real order processing, payment integration, inventory management, newsletter storage and backend contact submissions are not connected.

Product photography currently uses remote Unsplash images.
